# Examples Directory

Place **only** sample images or short video clips here for which you have verified redistribution permission and privacy clearance (no unconsented identifiable faces or restricted academic dataset images).

- The candidate files in the original `bitirme foto video/` folder (`58.jpg`, `100people.jpg`, `551.jpg`, `570.jpg`, `1588.jpg`, `test29.mp4`, `test33.mp4`) have **not** been copied into this directory because their redistribution rights are unconfirmed (`58.jpg` was verified by SHA-256 hash to be a copy of `ucf_qnrf/test.jpg` from the restricted UCF-QNRF dataset).
- Note that `.gitignore` ignores `*.jpg`, `*.png`, and `*.mp4` by default as a safety measure; if you later add approved public sample assets here, add an explicit `!examples/<filename>` exception in `.gitignore`.
